# Workflows — end-to-end walkthroughs

Task-oriented guides that string individual commands into a real job. Each one is
grounded in actual command paths from [../domains/index.md](../domains/index.md); flags
shown are the important ones — see the per-domain reference for the complete list.

1. [Authenticate & verify](01-authenticate.md) — log in once, confirm token storage.
2. [Build a Journey Orchestrator program](02-build-jo-program.md) — create → source → email node → flow → validate → publish.
3. [Author a Rules Engine rule with a CTA](03-author-rule-with-cta.md) — the Step 1–4 rule-builder pipeline.
4. [Build a Data Designer template](04-build-data-designer-template.md) — extract/merge tasks → preview.
5. [Ad-hoc data exploration](05-adhoc-exploration.md) — describe objects, query, run reports.

> Conventions: `<…>` marks a value you supply. JO and rules use a **short alias** form
> (`jo p`, `re r`); the full form (`journey programs`, `rules-engine rules`) works too.
